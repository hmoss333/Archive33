The Archivist is a psychological horror game set in a decaying records facility. As the lone archivist, you must use an old radio system to determine where each file belongs, guided only by distorted transmissions from the unseen Control. With every document, the line between order and chaos begins to blur. Finish the work and uncover what the facility is really trying to contain.


Controls

    Mouse to interact with the environment
    A/D Keys to tune the radio
    W/S + Space to toggle fuses
